# 🍽️ Restaurant Data Analysis

## 📌 Project Overview
This project focuses on analyzing restaurant data using Python to discover insights about cuisines, restaurant ratings, locations, pricing, online delivery, and restaurant chains.

## 🎯 Project Objectives
- Identify the most popular cuisines.
- Analyze restaurant distribution across cities.
- Understand restaurant ratings and customer votes.
- Compare online and offline delivery trends.
- Study restaurant price ranges.
- Analyze restaurant chain performance.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib

## 📊 Tasks Performed

1. **Cuisine Analysis** – Identified the top 3 cuisines and calculated their percentages.
2. **City Analysis** – Analyzed restaurant counts and average ratings across cities.
3. **Price Range Analysis** – Studied restaurant distribution by price range.
4. **Online Delivery Analysis** – Compared online delivery availability and average ratings.
5. **Rating Analysis** – Visualized rating distribution and calculated the most common rating and average votes.
6. **Cuisine Combination Analysis** – Identified popular cuisine combinations and compared average ratings.
7. **City-wise Visualization** – Created a bar chart showing the top 10 cities by restaurant count.
8. **Restaurant Chain Analysis** – Compared restaurant chains by number of outlets, average ratings, and votes.

## 📈 Key Visualizations
- Restaurant rating distribution
- Top 10 cities by restaurant count
- Price range distribution

## 💻 Python Libraries
- pandas
- matplotlib

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Install the required libraries:

   `pip install pandas matplotlib`

3. Place the `Dataset.csv` file in the same folder as the Python scripts.
4. Run the required Python task file:

   `python level1_task1.py`

5. Explore the analysis results and visualizations.

## 📁 Dataset
The Python scripts expect a file named `Dataset.csv`. Add the dataset to the project folder before running the scripts.
